# Temas del Curso

## TEMA 01 — Identidad y Usuarios

**Detalle**
- Registro y autenticación
- Roles: admin, responsable, profesor, alumno
- Perfil de usuario
- Auditoría
- Borrado lógico y retención configurable

**Extra**
- Puerta de enlace de API (API gateway)
- Personalización avanzada de perfil

## TEMA 02 — Cursos y Matrícula

**Detalle**
- Alta de curso
- Comisiones
- Inscripción de alumnos
- Ciclo de vida y archivado

**Extra**
- Servicio de presencialidad

## TEMA 03 — Motor de Desafíos

**Detalle**
- Ciclo de vida del desafío
- Publicación y asignación
- Entregas y estados
- Versionado

**Extra**
- Colaboración en desafíos

## TEMA 04 — Teóricos y Encuestas

**Detalle**
- Ítems teóricos
- Corrección
- Encuestas con anonimato desacoplado

**Extra**
- Banco de ítems con etiquetado por tema

## TEMA 05 — Desafíos Prácticos

**Detalle**
- Consignas de código
- Casos de prueba
- Formato de entrega
- Feedback al alumno

**Extra**
- Anti-cheat por similitud entre entregas

## TEMA 06 — Sandbox / Runtime

**Detalle**
- Ejecución aislada
- Límites de CPU, memoria y tiempo
- Captura de salida

**Extra**
- Almacenamiento de artefactos de ejecución

## TEMA 07 — Evaluación LLM

**Detalle**
- Rúbricas
- Invocación del modelo
- Golden set base y calibración por curso
- Bloqueo de activación de curso

**Extra**
- Configuración centralizada
- Tablero de deriva del evaluador

## TEMA 08 — Banco

**Detalle**
- Ledger de movimientos
- Transacciones
- Saldos
- Reglas de acreditación

**Extra**
- Historial de movimientos exportable
- Reversión de transacciones con traza

## TEMA 09 — Mercado

**Detalle**
- Catálogo
- Compra
- Inventario del alumno
- Consumo de ítems

**Extra**
- Intercambio entre alumnos
- Subastas

## TEMA 10 — Roadmap y Progreso

**Detalle**
- Grafo de contenidos
- Prerequisitos y desbloqueo
- XP y niveles
- Logros

**Extra**
- Visualización del recorrido
- Comparativas de cohorte

## TEMA 11 — Social y Notificaciones

**Detalle**
- Chat: no se retiene, se purga al archivar, excepción por reporte
- Equipos
- Notificaciones
- Reportes de contenido

**Extra**
- Mensajería asíncrona como servicio

## TEMA 12 — Backoffice

**Detalle**
- Administración de plataforma
- Gestión del proveedor de modelo, exclusiva de admin
- Reportes docentes

**Extra**
- Exportación de datos
- Panel de métricas de curso
